Google Apps Script Setup

  1. Open your Google Sheet, click Extensions > Apps Script.
  2. Click Copy Apps Script Code above, paste it into the editor, and click Save (💾).
  3. In Project Settings > Script properties, set GEMSENTRY_WEBHOOK_SECRET to the same secret saved above.
  4. Click Deploy > New deployment > Web app. Set Execute as: Me, Who has access: Anyone. Click Deploy, copy the Web app URL, and paste it into the field above!
  5. For an existing deployment, deploy a new version. Save settings, then click Test Webhook.
